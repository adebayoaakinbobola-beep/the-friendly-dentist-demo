# The Friendly Dentist

A modern, responsive dental website concept for **The Friendly Dentist** in Blackrock, Co. Dublin. The project combines a patient-friendly presentation with a distinctive 3D-inspired visual experience.

## Live Demo

https://the-friendly-dentist-demo.vercel.app

## Project Overview

The Friendly Dentist is a front-end portfolio concept focused on presenting dental care in a calm, approachable and contemporary way. The experience uses clear content sections, strong calls to action and interactive visual details to help visitors explore the practice and its treatments.

> **Portfolio note:** This is an unofficial website concept created for demonstration and portfolio purposes.

## Key Features

- Responsive React interface
- Modern 3D-inspired hero presentation
- Subtle desktop parallax interaction
- Reduced-motion support for accessibility preferences
- Treatment and care sections
- Practice/about content
- Patient-experience section
- Click-to-call action
- Responsive navigation and footer
- Accessible semantic structure and ARIA labels

## Tech Stack

- React
- TypeScript
- Vite
- CSS
- Lucide React icons
- Oxlint
- Vercel for deployment

## My Contribution

I developed and refined this dental website concept with an emphasis on modern visual presentation, responsive layout, approachable patient messaging, clear navigation, interactive details and accessibility-conscious motion behavior.

## Project Goal

The goal of the project is to demonstrate how a dental practice website can combine a warm, trustworthy patient experience with a more distinctive visual identity and interactive front-end presentation.

## Run Locally

```bash
git clone https://github.com/adebayoaakinbobola-beep/the-friendly-dentist-demo.git
cd the-friendly-dentist-demo
npm install
npm run dev
```

For a production build:

```bash
npm run build
```
